# Apps I've built

A collection of small web apps I designed and built with Claude. Each one is a single self-contained `index.html` with no build step and no sign-up.

These are blank copies. Anything you type is saved in your own browser only and is never sent anywhere. The screenshots below use made-up example data.

| App | What it does |
| --- | --- |
| [Wedding planner](wedding-planner/) | Tasks, vendors, guest list with RSVPs, addresses, seating plan, menu choices, running order, photo shot list and a wine-tasting scorer |
| [Wedding budget](wedding-budget/) | Budget by category with paid and outstanding totals, venue breakdown, menu option comparison, savings tracker and backups |
| [Personal budget](personal-budget/) | Month-by-month budget with income, variable and fixed spend, savings pots, a loan repayment tracker and an overview across months |
| [Skin and health tracker](skin-and-health-tracker/) | Daily skincare routine and LED mask course, gym plan, cycle and gut tracking, and insights |
| [Packing lists](packing-lists/) | Reusable packing lists per trip type with tick-off, N/A and editing modes |
| [Dates to remember](dates-to-remember/) | Log the little dates worth a message so nothing gets missed |
| [Positive log](positive-log/) | Record good moments and how they made you feel, with levels and recaps |

## Running them

Open any `index.html` in a browser, or turn on GitHub Pages for this repo (Settings > Pages > Deploy from branch) and each app gets its own link.
